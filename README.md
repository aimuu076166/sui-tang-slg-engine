# 隋唐风云·战略版

**Sui-Tang Tactics SLG Engine**

[![Python 3.10+](https://img.shields.io/badge/python-3.10%2B-blue.svg)](https://www.python.org/downloads/)
[![MIT License](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

隋唐架空历史战争策略游戏原型。战斗模块负责回合结算和战报，地图模块负责生成六角沙盘和判断连地条件。两个模块都在同一个 Python 文件中运行，仅依赖标准库。项目面向手机竖屏玩法，计划以 Vanilla JS Canvas 制作交互原型，并为微信小游戏和服务端接入保留各自的模块边界。

## 快速开始

```bash
python3 sui_tang_slg.py
```

命令会打印一场太原铁骑对禁卫龙骧军的战报，以及从主城附近对 `(1, 0)` 发起出征的连地判定。内置样例为唐军三将对隋军两将。选敌、战法触发和资源地生成使用随机数。

## 当前战斗模型

- **速度与目标**。存活武将按速度降序行动，从敌方存活武将中随机选敌。主将兵力归零即判全队失败，副将存活也会结束战斗。默认最多结算 8 个回合。
- **士气**。士气在伤害计算时按 0–100 限定。`MoraleFactor = 0.3 + 0.7 × (士气 / 100)`，满士气系数为 1.0，零士气为 0.3。基础伤害为 `(武力 × 1.5 − 目标统率 × 0.8) × (当前兵力 / 1000) × MoraleFactor`，取整后最低为 50。
- **震慑**。受震慑的武将跳过下一次行动，随后解除状态。数据模型预留计穷字段。
- **战损**。战报将兵损分别按 55% 阵亡、45% 轻伤向下取整，两项合计可能比实际兵损少 1。医馆救治属于后续玩法。
- **结算接口**。`BattleEngine(attacker, defender).run_battle()` 返回进攻方是否获胜及战报，并更新传入队伍的兵力。回合耗尽且守方未溃败时，胜负标记为 `False`。

## 当前沙盘模型

`HexMap` 使用轴坐标 `(q, r)` 生成六角地图，包含农田、林场、铁矿、主城与关卡。地图记录等级、地块归属和驻军兵力。`get_neighbors(q, r)` 返回地图内的邻地，`can_attack(player_name, target_coord)` 判定目标是否接壤己方地块。调用方需要另行检查目标坐标与地块归属。

## 后续玩法

- **战斗**。完整 3 对 3 阵容、计穷下仅可普攻、混乱下可攻击双方单位、普通与物理攻击援护，以及伤兵回城消耗资源救治。行军中通过扎营或沿途补给恢复士气。
- **资源与调遣**。农田、林场、采石场按等级每小时产出 `Level × 40`。长安、洛阳等封地或名城每小时基础产出 60 黄金与 20 铜钱。计划通过 BFS 寻路和网格插值展示行军，沿途触及敌方驻军时进入遭遇战。
- **竖屏原型**。计划制作 `miniapp_slg_prototype.html`，适配 375×667 及以上视口，支持双指缩放、拖动沙盘、地块出征、驻守、放弃和底部战报。页面完成后可直接打开，或用 `python3 -m http.server 8080` 启动静态预览，访问 [本地预览页](http://localhost:8080/miniapp_slg_prototype.html)。
